# Provider capability audit

Reviewed official sources on 18–19 October 2026. **Documentation verification is separate from live verification.** After an initial rejected trial request and two busy executions, a separately approved two-participant test produced one busy equipment call and one answered delivery call. The delivery call completed in 100 seconds, returned a transcript and reported 12 US cents with billing pending. Its authenticated scoped brief fetch was persisted by the server, proving runtime capability substitution and one live read tool. No observations/offers or shared live coordination resulted. Context and conversation corrections from that transcript are implemented but not yet retested live. No automatic redial is scheduled; provisional allowances remain reserved and normal live switches are off. Temporary callbacks were stopped after the rehearsal. Paid browser voice remains unverified. See VERIFICATION.md.

## Number-free browser conductor

Implemented independently of paid telephone services: browser SpeechRecognition input, typed fallback, optional SpeechSynthesis replies, two mission templates, deterministic natural constraint extraction, status/revision/pause/resume/retry commands, persisted source-labelled input and replies, and explicit approval-card handoff. No phone number is required. Desktop/mobile tests exercise the actual authenticated API and persistence. The speech protocol uses an explicit test double, so hardware microphone capture and recognition quality are not claimed as measured. Browser support and speech-service connectivity vary; typed input remains available. See [SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition) and [SpeechSynthesis](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis).

Known boundary: a pause received after the worker admits a network request cannot retract that request. It blocks later admission and approvals. Active calls retain read/report tools until expiry, can read paused=true, and may finish politely. No automatic ambiguous-call retry occurs. Dated authorizations expire; durable phone/browser reserves share one total ceiling across missions and restarts. Provider invoices determine actual charges. Repeated terminal updates can enrich transcript/recording/cost evidence; at most six bounded artifact polls continue without redialing.
